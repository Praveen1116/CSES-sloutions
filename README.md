# CSES Problem Set

This repository contains my solutions to problems from the [CSES Problem Set](https://cses.fi/problemset/), implemented in C++.

I am actively working through the problem set to improve my problem-solving and competitive programming skills, and I will continue adding new solutions as I solve them.

### Compile & Run

```bash
g++ -O2 <filename>.cpp -o solution
./solution
```
